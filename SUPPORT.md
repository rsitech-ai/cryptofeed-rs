# Support

cryptofeed-rs is community-supported alpha software. RSI Tech does not currently
offer an uptime, compatibility, or response-time SLA for this repository.

## Where to ask

- Reproducible bugs and feature requests: GitHub Issues.
- Usage and design questions: GitHub Discussions, when enabled.
- Security-sensitive reports: follow [`SECURITY.md`](SECURITY.md).
- Public or confidential project contact:
  [info@rsitech.ai](mailto:info@rsitech.ai).

Before opening an issue, search existing reports and include:

- cryptofeed-rs version or commit SHA;
- operating system, architecture, and Rust version;
- venue, segment, channel, and a redacted minimal configuration;
- expected and observed behavior;
- relevant sanitized logs and metrics.

Never post API keys, secrets, account identifiers, private recordings, or
customer data. Live exchange availability, schemas, and rate limits are outside
the project’s control.
