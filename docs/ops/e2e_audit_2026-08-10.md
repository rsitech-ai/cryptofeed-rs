| high | Runtime performance | maintaining two cloned Market Profile accumulators made per-trade work grow with session state and eventually starved Coinbase heartbeats | keep one exact accumulator and choose Volume/TPO only when snapshotting | isolated source probe was healthy; repaired 263-second full run had zero heartbeat reconnects |

## Residual Limits

- The parser benchmark has fresh absolute measurements but no checked local baseline, so it is not comparative regression evidence.
- The depth-history service intentionally remains bounded at 3,000 samples (about five minutes at 100 ms). Expanding the original 15-minute concept with string-heavy full-depth snapshots would materially increase memory; a packed representation should precede longer retention.
- The DOM is market-by-price, not market-by-order. No queue position or individual order identity is claimed.
- This pass proves a bounded live public-data runtime, not a multi-day production soak or private exchange coverage.

## Final Readiness Label

- Label before Git integration: release-ready candidate; runtime-proven for the exercised public-data paths
- Blockers: none in the authorized read-only scope
- Follow-up: add a versioned parser baseline and packed depth-history storage before increasing retention
