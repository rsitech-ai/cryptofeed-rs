# Bootstrap and durable factory gate

The opt-in causal bootstrap now binds exact typed factory/category, ordered
session/channel/delivery policy and effective native topics, full exact catalog,
capture and effective runner limits, embedded verified public input bytes and
observed source/build/lock/selected-feature/executable identity. Canonical payload
hash and owner identity are checked before any factory construction. The actual
writer actor's post-barrier receipt is required to create the private persistent
CaptureSession. Rejected admission retains the same prepared bootstrap; dropped
waiters do not cancel accepted storage work. See the
[profile contract](../../plan/causal_bootstrap_factory_profile.md).

The first supported profile is public production Bybit spot/linear/inverse with
the complete native bundle and disk/null dispatch. Review closed two findings:
unsupported channel/delivery combinations now fail before ACK instead of
pretending the legacy adapter honors them, and workspace fingerprinting is
explicitly gated so ordinary builds retain their prior layout. Arbitrary legacy
channel subsets remain unqualified outside this profile.

A real regression reproduced nondeterministic Bybit book invalidation order.
Ordered book/quote maps now retain deterministic effects across fresh actual
factories. Ten focused bootstrap tests pass; independent combined daemon,
engine and Bybit verification passes **396 tests**, with zero failures and four
existing ignored tests, including three separate public bootstrap regressions.
The independent default-feature public check also passes. The earlier workspace
snapshot passed **1,407 tests**, with zero failures and 56 existing ignored
tests, before two independently reviewed lint fixes: equivalent map membership
and boxing the private retained bootstrap value. The final affected-package
suite follows both fixes. See the [validation receipt](validation.json) for the
exact source scope, Rust 1.85, static/security and staged public checks. The
new source still requires its own hosted full-workspace qualification.

The independent [build-binding receipt](build-binding.json) recomputes the
declared 520-file source snapshot and verifies exact generated recipe bytes in
the observed retained unit-test executable. It preserves older generated files
and all scope limits. This fingerprints declared inputs and a preserved
executable file; it does not prove loaded-image identity, signed attestation,
complete transitive build-input closure or bit-reproducible compilation.

The preceding codec source completed all 17 hosted jobs, separately qualified
in its own [receipt](../engine-operation-codec-20261020/ci-qualification.json).
Hlscreen's exact published source now passes main and all four native artifact
jobs, with raw validation logs checked for the earlier Windows decoding defect.
Its [source-scoped receipt](consumer-qualification.json) preserves the old false
success as unqualified. Shared source/effective dependencies remain unchanged,
so hlscreen retains its existing feed pin; no whole-producer equivalence follows.

This is a bootstrap/factory boundary, not a live journal owner. Operation
commit/release, bound external sink intents, committed consumer projection,
actual-engine replay/resume and daemon/live migration remain unfinished. The
registered ingress workload remains failed and was not rerun. Native semantics/
continuity, strict datasets, rsibot context/features, calendar and hardware gates
remain open. No economics, release publication or operational promotion follows.
